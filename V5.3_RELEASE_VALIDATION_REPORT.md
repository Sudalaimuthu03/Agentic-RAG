## Important environment limitation

The complete runtime release gate cannot honestly be marked PASS in this sandbox. The project requires Python 3.11, while the available interpreter is Python 3.13.5, and the environment lacks `langchain_core`.

The final production release decision must therefore be made after running the ZIP in the intended Python 3.11 virtual environment with the project's real dependencies and model provider.

## Required target-environment verification

Run:


Then run the complete conversational regression against the actual local/Ollama or configured NVIDIA provider and inspect the forensic log for:

Do not declare V5.3 production-ready until those target-environment checks pass.
